# Discharge workflow checklist

DischargeCare's steps, as the tool records them. A clinician decides what goes in the plan.

1. Create the discharge episode.
2. Add instructions for the family, written by staff.
3. Record barriers, with an owner for each, and resolve them.
4. Record results still awaited, and finalise each when it arrives.
5. Add tasks for the patient and the team.
6. A clinician approves the plan.
7. Close the episode when nothing is left open.
